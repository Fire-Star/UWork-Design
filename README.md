# UWork 企业智能体 · 原型设计

UWork 是公司自研的企业智能体工作台。本仓库包含同一套演示数据驱动的两个原型，并沿用原有客户端的浅灰桌面风格与管理端的 Element 管理台风格：

- [客户端原型设计/index.html](客户端原型设计/index.html)：员工侧智能体工作台
- [管理端原型设计/index.html](管理端原型设计/index.html)：企业侧运营管理台
- [shared/uwork-data.js](shared/uwork-data.js)：两端共用的演示数据（知识库、模板、模型、技能、连接器、用户、密级等）
- [shared/uwork-store.js](shared/uwork-store.js)：本地数据层与密级过滤规则

原型为纯静态 HTML/CSS/JavaScript，无需构建。管理端在原 7ad070cc-c077-42ac-9b0b-f4e4e9a7c7ed/admin.html 的信息架构与视觉语言基础上重构。

## 快速体验

推荐在仓库根目录启动一个静态服务器，保证两个原型共享同一份本地存储：

    python -m http.server 8765

然后访问：

- 客户端：http://127.0.0.1:8765/客户端原型设计/index.html
- 管理端：http://127.0.0.1:8765/管理端原型设计/index.html

直接双击 index.html 也能打开基本交互，但 file:// 下浏览器可能按文件隔离 localStorage，管理端修改不一定会同步到客户端。

## 客户端

- **登录**：企业账号 + 密码登录，登录后展示姓名、部门与账号密级；支持退出与切换账号。
- **新会话**：四个初始智能体「通用办公 / 质量体系 / 保密体系 / 产品设计开发」，默认通用办公，不再展示 PTC / 标准模式下拉。
- **工作区 / 工作目录**：输入框左下角可切换工作目录（默认工作区，或质量体系 / 8D 分析、保密体系 / 涉密载体等目录），也支持「选择本地目录…」指定本机文件夹；未选择目录时使用默认工作区。左侧「工作区」按目录列出会话：目录行可折叠、显示会话数，会话行显示标题与相对时间（刚刚 / 1小时 / 1天），超过 5 条时可「展开其余 N 个会话」；标题栏提供搜索会话、按最近活动 / 名称排序、新增工作目录（选择本地文件夹）三个入口。
- **文件权限**：输入框左下方新增权限下拉，默认「工作区内修改」，可切换「仅可查看 / 工作区内修改 / 完全权限」；选择结果随会话保存，对话过程卡片会标注本次执行使用的权限。
- **加号菜单**：
  1. 添加文件 → 本地文件
  2. 知识库 → 从有权访问的知识库中选择
  3. 技能 → 搜索、已集成技能列表、从本地添加技能、管理技能
  4. 连接器 → 搜索、可连接连接器、管理连接器
  5. 文档模板 → 目录层级勾选弹窗
- **知识库选择器**：按账号密级展示知识库 → 目录 → 文档，支持勾选整个知识库、目录或单个文档，输入框中以可移除标签展示。
- **文档模板选择器**：按目录层级勾选模板或整个目录，选择后回填输入框。
- **侧边栏知识库**：卡片列表、搜索、新建知识库；进入后可查看目录层级与文档，文档展示「已治理 / 待治理」，有权限时可执行智能治理。
- **侧边栏文档模板**：目录树 + 模板列表，按权限区分可编辑 / 只读；支持新建目录、上传模板、预览、带入对话、编辑有权限的模板。
- **对话**：四个智能体的示例过程与结构化答复，展示引用来源；发送时自动带入已选文件、知识库、技能、模板；打开历史会话时工作目录自动切换到该会话所属目录。
- **软件更新**：用户菜单 → 检查更新，读取管理端发布的最新版本并比较版本号；展示更新说明、安装包信息，支持下载进度与「重启后生效」；低于最低支持版本时进入强制更新提示。
- **消息中心**：左下角账号旁的铃铛（顶栏铃铛同步）打开消息中心，按账号密级展示管理端「通知公告」中已发布的通知；支持未读计数、展开阅读、全部已读，阅读状态按账号保存在本地。

## 管理端

一级菜单顺序固定为：知识库、文档模板、模型管理、技能管理、连接器管理、软件更新、通知公告、审计日志、系统管理（最后）。

- **知识库**：新建（名称、描述、部门、密级、负责人）、搜索、编辑、删除；负责人为下拉多选，仅负责人可编辑该知识库，不选负责人时所有有权限的员工都能编辑；进入详情后左侧目录树、右侧文档列表，支持新建目录、上传资料（PDF / Word / Excel / PPT / TXT / MD / PNG / JPG）与智能治理。
- **文档模板**：目录树 + 模板列表，新建目录（目录可指定所属部门，仅该部门成员可见，留空则所有部门可见）、上传模板（doc / docx / xls / xlsx，拖拽上传、默认文件名、分类、密级）、编辑、删除。
- **模型管理**：新增、编辑、删除、启停、设为默认，模型带数据密级。
- **技能管理**：上传 `.zip` 技能包（拖拽或点击选择，仅支持 zip、单个不超过 200 MB），新增、编辑、删除、启停；技能列表展示技能包名称与大小，并带分类、版本、调用次数与密级。新增技能时技能包必填，选择后自动从包名带出技能名称与版本。
- **连接器管理**：新增、编辑、删除、连接 / 断开，连接器带接入地址与密级。
- **软件更新**：发布客户端版本（版本号、正式 / 灰度渠道、平台、可选 / 强制更新、安装包与更新说明）；右上角「更新策略」维护最低支持版本、更新渠道与检查频率；支持草稿、发布、下架、重新发布与删除。
- **通知公告**：发布面向客户端的通知公告（标题、类型、数据密级、发布人、状态、正文），支持搜索、状态筛选、新增、编辑、发布与删除；已发布通知按密级推送到客户端消息中心，草稿仅管理端可见。
- **审计日志**：知识库、知识文档、文档模板、模板目录的新增 / 编辑 / 删除 / 查看自动写入审计记录，支持按对象类型、操作、关键词筛选追溯；记录只读，不提供修改。原「系统管理 → 日志管理」已并入该模块。
- **系统管理**：
  - 用户管理（账号、部门、角色、岗位、密级、状态）
  - 角色管理（数据范围、密级上限）
  - 密级管理（密级标签列表，新增 / 编辑 / 删除，被引用时禁止删除）
  - 菜单管理、部门管理、岗位管理、字典管理、参数设置

## 密级标签与闭环

密级是数据上的可见性标签，默认五级（顺序 1–5），可在「密级管理」自行维护：

| 密级 | 规则 |
| --- | --- |
| 公开 L1 | 所有员工可见 |
| 内部 L2 | 内部级及以上可见 |
| 秘密 L3 | 秘密级及以上可见 |
| 机密 L4 | 机密级及以上可见 |
| 绝密 L5 | 仅绝密级可见 |

- 用户、角色、岗位、知识库、知识文档、文档模板、模型、技能、连接器与通知公告都绑定密级标签。
- 客户端只展示「数据密级顺序 ≤ 用户密级顺序」的数据；高于账号密级的数据在选择器中完全不返回。
- 「密级管理」是一张密级列表（名称 / 描述 / 操作），支持新增、编辑、删除标签：可设置名称、级别顺序、标签颜色与说明；列表按级别顺序排列，新增后立即出现在所有密级选择项中。
- 标签被引用时不可删除：删除前会校验用户、角色、岗位、知识库、知识文档、文档模板、模型、技能、连接器与通知公告，并提示引用明细；至少保留一个标签。
- 管理端修改用户密级或数据密级后，客户端重新登录 / 刷新即可看到最新范围；「密级管理」页顶部的「打开客户端验证」可直接以张明（秘密级）查看客户端过滤结果。
- 演示数据中，张明（秘密级）可见 5 个知识库、11 个模板、5 个模型、9 个技能、8 个连接器；机密 / 绝密内容被隐藏。

## 演示数据与重置

演示数据位于 [shared/uwork-data.js](shared/uwork-data.js)，两端通过 [shared/uwork-store.js](shared/uwork-store.js) 读取并在 localStorage 中持久化，键名：

    uwork.prototype.db.v3

体验过程中新增的知识库、上传记录、治理状态、用户、模型等都会保存在本地。恢复初始数据：

- 打开 客户端原型设计/index.html?reset=1 或 管理端原型设计/index.html?reset=1，会自动清空并刷新，同时清除客户端消息的已读状态（`uwork.client.messages.read`）；
- 或在浏览器开发者工具中删除上述 localStorage 键。

上传的文件只保存名称、格式、大小等演示元数据，不会写入真实文件；技能包与客户端安装包同样只记录文件名、大小与上传时间；智能治理用 1 秒左右的模拟过程表示。客户端更新中的下载与重启为演示流程。
